# harbourleaf-labs

Practice labs for **UpModel** learners: the hands-on Tasks behind each chapter.

> **Everything here is fictional.** Harbourleaf, Rowanbridge Data Systems, the bookshop, every order, score, attack and person in these files is invented for teaching. No real customer data, credentials or keys are used, and none should ever be added.

## How to use it

1. Open the folder for your chapter's Task (below) and read its `README.md`.
2. Work in whichever editor you like:
   - **VS Code** with the Python extension, on your own laptop
   - **Google Colab** in the browser, with no install
   - **GitHub Codespaces** (from the Python for Testers module, Chapter 6): **Code → Codespaces → Create codespace**
3. Paste your script and its output into the Task panel in UpModel. Ask the AI Tutor if you're stuck.

**Your copy, your work:** fork this repo (**Fork**, top right) to keep your solutions on your own GitHub account. Nothing you do changes this repo.
