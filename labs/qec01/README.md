# labs/qec01 · Quality Engineering Core · chapter 1 · Test strategy and risk-based testing

Practice files for the chapter 1 demo and Task HLF-P51. Everything here is fictional.

## You need
- A spreadsheet: Excel, Google Sheets or LibreOffice. Nothing to install.
- For the pull-request step in chapter 5 only: a free GitHub account. Not needed here.

## Files
- `demo/room_match_note.md`: the feature note used in the demo video.
- `task/bundle_and_save_note.md`: the feature note for Task HLF-P51.
- `task/UpModel_QEC_Ch1_Test_Plan_Template_v1.xlsx`: the test plan template. Fill the yellow cells; on every sheet except Read Me and Then and Now, the grey italic row 5 is an example, not your answer.

## How to work
1. Read the feature note, then get the template: open `task/UpModel_QEC_Ch1_Test_Plan_Template_v1.xlsx` on GitHub and choose the download icon (Download raw file).
2. Build your risk sheet in a blank sheet. Likelihood and impact are 1 to 5, and level is likelihood multiplied by impact.
3. Work through the Task steps in order. Give a reason for every choice.
4. Practice files only for the AI step, never real or work data.
